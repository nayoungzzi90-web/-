## 2. 공개 공식 기준 대조 — KASI (한국천문연구원)

  - 2026: https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2026

- 표본: 2025·2026·2027년 각 12절 = **n = 36**, KST 분 단위 해상도

**중요 — 기준의 성격:** KASI 사이트의 `calendarData`는 공개적으로 표시되는 참고용 데이터셋으로, 법적 관보로 공표되는 **월력요항과 사이트 스스로 구분**해 안내한다. 따라서 이 대조는 "분 단위 공개 기준과의 일치" 확인이며 **초 단위 ground truth 입증은 아니다**.

## 4. 구조적 회귀 검증 (통과)

- 1월 소한 → **이전 해 인덱스 [11]** 매핑 (`solarTermsUtc(y-1)[11]`) 정상
- 연말·연초 년주/월주: 1900 庚子년 壬午月, 1988 丁卯년 癸丑月, 2000 庚辰년 戊子月
- 일주 60순환 기준일: 2000-01-07 甲子 / 벤치마크 1995-03-21 辛亥, 1990-04-19 甲寅
- 서머타임 **중복(ambiguous)** · **소멸(nonexistent)** 현지 시각 → fail-closed 차단
- 기본 `midnight` / 옵트인 `zi23` 정책 분리, `zi23` + 출생시간 미상은 "일주 모호"로 차단
- 절입 경계 ±120초 이내 → `needsReview`(검토 필요) 표시
- 잘못된 입력(시간 문자열 8종, 임의 JSON/null/array, `leap` 타입, 빈 `time`, 음력/윤달) → 사용자용 일반 오류, 스택 미노출
- 테스트 상태: vitest 30건 통과, tsgo 타입 검사 통과, build OK

## 5. 남은 NO-GO (운영 미승인 사유)

1. **NASA JPL DE440s 직접 고정밀 검증 미수행** — Swiss는 Moshier로 비교함.
2. **역사적 시간법( timezone law) 출처 교차 확인 미완료** — 1900년대~1980년대 법정시·서머타임 적용 근거 원문 대조.
3. **음력·윤달 미지원** — 변환 없이 fail-closed 안내만.
4. **R-002~R-014 운영·전문가 검수 게이트 미이행**.
5. **실 사용자 인증 API / RLS 권한 테스트 미완료** — anon·본인 외 접근 차단 확인은 별도 단계.
6. 따라서 `finalApproved=true`로 전환하지 않고, **유료 결제·상품 활성화는 하지 않으며**, UI는 비공개 상태로 유지한다.
