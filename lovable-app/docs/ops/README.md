# 운영 DB 읽기 전용 스냅샷 — 실행 안내 (R015 0단계)

**이 작업은 아무것도 바꾸지 않는다**(SELECT 한 문장). 그래도 운영 DB 이므로 **사용자 본인이 직접** 실행한다.

1. Lovable 프로젝트의 DB 화면에서 SQL 을 실행할 수 있는 곳을 연다(없으면 Lovable 채팅에 "이 SQL 은 읽기 전용입니다. 그대로 실행해서 결과 JSON 을 보여 주세요"라고 요청해도 된다 — 어느 쪽이 가능한지는 직접 확인 필요).
2. `R015_PROD_READONLY_SNAPSHOT.sql` 전체를 붙여넣어 실행한다. 결과는 `snapshot` 한 칸에 JSON 한 덩어리.
3. 그 칸을 통째로 복사해 이 대화로 보낸다. **공개 저장소(GitHub)에는 올리지 않는다**(권한·함수 본문 등 보안 정보 포함).
4. 개인정보는 출력되지 않는다(개수·집계만). 그래도 보내기 전에 한 번 훑어본다.
5. 받으면 `node scripts/analyze-snapshot.mjs 결과.json` 으로 자동 점검 + 함수 본문은 사람이 읽고 검토한다.

실행이 거부되거나 오류가 나면 오류 문구를 그대로 보내 달라(예: `pg_default_acl` 권한 없음이면 해당 구역만 빼고 다시 만든다).
