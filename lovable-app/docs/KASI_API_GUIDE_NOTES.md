- 불일치 1건: **2011-11-08 입동** — KASI API `kst=0926`, 우리 03:35 (차이 -351분). 이 항목의 KASI `sunLongitude` 는 225.
- 독립 확인(astronomy-engine, 같은 엔진이므로 증거의 일부일 뿐): 태양 겉보기 황경은 03:35 KST 에 224.9999°, 09:26 KST 에 225.2444°. 즉 KASI 가 이 레코드에 직접 적은 황경 225°와 시각 09:26 이 **서로 모순**이고, 03:35 쪽이 물리적으로 일치한다. 자체 DE421 엔진도 03:34:55 UTC+9 로 같다.
- 결론: 우리 엔진 오류가 아니라 **KASI API 레코드 오류일 가능성이 높다**. 다만 공식 확인이 아니므로 KASI 에 문의하거나 월력요항 등 다른 공식 자료로 재확인해야 한다. 이 한 건 때문에 "공식과 100% 일치"라고 쓰지 않는다.
- 범위 해석: 이 대조는 **12절(節) 시각의 2000~2027 구간**이다. 1900~1999 는 API 에 데이터가 없고 2028~2050 은 API 갱신 전이라 공식 대조가 불가능하다.
