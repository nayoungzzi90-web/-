## 이 서비스의 실제 동작에 맞춘 사실(코드 기준)
- 엽전 1닢 = 900원. 기본 사주 1닢, 궁합 1닢, 심층 연애운 2닢, 택일 2닢, 심층 사주 3닢. 충전은 1~4닢 팩.
- 가입 보너스 없음. 초대 보상 1닢은 **초대받은 친구가 처음 결제**했을 때, **초대한 사람이 먼저 1닢 이상 결제**한 경우에만 지급(한국 시간 하루 3명·월 10명).
- 엽전은 한 개의 잔액이라 유상/보상 구분이 없다. 그래서 **풀이를 한 번이라도 연 뒤에는 이전 결제를 자동 환불하지 않는다**(수동 처리).
- 회원 탈퇴 시 출생정보·열람 기록·초대 코드·지갑·로그인 계정은 즉시 삭제, 결제·원장 기록은 가명 상태로 보관 후 삭제(기간은 결정 필요).
- 결제 기능과 탈퇴 기능은 현재 꺼져 있다(미출시).
