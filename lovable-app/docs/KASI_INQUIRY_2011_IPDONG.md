# KASI 문의 초안 — 2011-11-08 입동 시각 (2026-10-18)

대안: 공공데이터포털 '한국천문연구원 특일 정보' 상세 페이지의 문의(Q&A) 게시판.

제목: [특일 정보 API] 2011년 입동(24절기) 시각이 태양황경과 맞지 않는 것으로 보입니다

안녕하세요. 공공데이터포털의 '한국천문연구원 특일 정보'(SpcdeInfoService) 24절기 API를 활용하고 있는 개발자입니다.
2000~2027년 12절(節) 336건을 별도 계산 결과와 비교했는데 335건은 1분 이내로 일치했고, 아래 1건만 약 6시간 차이가 납니다. 확인을 부탁드립니다.

■ 호출
GET http://apis.data.go.kr/B090041/openapi/service/SpcdeInfoService/get24DivisionsInfo?solYear=2011&ServiceKey=(생략)&_type=json

■ 응답에서 해당 항목
dateName: 입동, locdate: 20111108, kst: 0926, sunLongitude: 225, dateKind: 03

■ 의심되는 점
- 입동은 태양 황경 225° 순간입니다. 응답의 sunLongitude 도 225 입니다.
- 그런데 제 계산(astronomy-engine, 그리고 별도로 JPL DE421 기반 자체 계산)으로는 태양 겉보기 황경이 2011-11-08 03:35 KST(= 2011-11-07 18:35 UTC)에 225.000°이고, 09:26 KST 에는 225.24° 입니다. 즉 03:35 쪽이 황경 225°와 일치하고, 응답의 0926 은 약 5시간 51분 뒤입니다.
- 같은 해 다른 절기는 모두 1분 이내로 일치했습니다.

■ 문의
1. 2011-11-08 입동의 올바른 한국표준시각은 몇 시 몇 분입니까? (03:35 인지 09:26 인지)
2. 09:26 이 데이터 입력 오류라면 정정 계획이 있습니까?
3. 이 API 의 24절기 시각은 어떤 천체력과 계산식으로 산출된 값이며, 분 단위 이하는 반올림입니까 버림입니까?
