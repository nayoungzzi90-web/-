| 일간 | 파일 |

| 甲 | gap.webp | 乙 | eul.webp | 丙 | byeong.webp | 丁 | jeong.webp | 戊 | mu.webp |

- 기존 작품(참고 이미지)을 복제하지 말고 새로 제작한 에셋만 사용합니다. 상업 이용권 문서는 `docs/RELEASE_GATES.md` 의 캐릭터 항목에 증빙을 남깁니다.
- 이미지에 개인정보나 본문 텍스트를 넣지 않습니다. 소품/표정은 코드 레이어로 구현합니다.
