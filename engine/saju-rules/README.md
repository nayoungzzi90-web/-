# saju-rules — 기준서 R-002~R-005 결정론 엔진

`docs/saju-engine/source/R-002~R-005_spec_pasted.md` 를 코드로 옮긴 것. **계산 사실과 후보만** 만든다. 신강신약(R-006) 이후 판단, 좋고 나쁨, 강하고 약함은 하지 않는다.

| 규칙 | 파일 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| R-002 | `src/r002.ts` | 월지 → 계절 5구분, 왕상휴수사, 협의·광의 득령(두 값), 토월은 잠정 | 신강신약, 토월 세부(사령 반영) |
| R-003 | `src/r003.ts` | 《연해자평》 정적 지장간·본기, 사령 분일(normalized_30_v1, 경계 규칙, 시간 미상 시 복수 후보) | 《삼명통회》 분일(원문 수치 없음 → not_evaluated), 중기·여기 세부 분류 |
| R-004 | `src/r004.ts` | 4천간 × 4지지 통근 탐색: 같은 글자/같은 오행, 본기/비본기, 일지·월지 플래그, 원천 ID | 생조를 뿌리로 보기, 합충에 따른 변화, 확장 근기, 개수로 강약 |
| R-005 | `src/r005.ts` | 일간 기준 관계·십성·역할(지원/설기/소모/극제), 6쌍·인접성, 구조 후보(재극인 등), 간합(인접·사이·쟁합) | 일간을 비견으로 세기, 구조 성립, 합의 작용·합화, 득세 |

- 사령 분일표 `MODERN_30_CANDIDATE_V1` 은 **미검증 후보**라 사령 결과 상태는 `candidate` 를 넘지 않는다.
- 만세력 연결: `fromManse(ManseResult)` → `analyzeR002toR005(chart, { monthTerm, birth })`. R-001 이 운영 승인 전이라 모든 결과에 `upstreamApproved: false` 가 붙는다.
- 모든 결과에 규칙 ID·버전·근거 ID·원천(source) 이 있다. 같은 지장간은 원천 ID 하나로 식별해 중복 가산을 막는다(R-006 제8조 준비).
- 시험: `npx vitest run engine/saju-rules` — 120개 왕상휴수사(손으로 적은 전통 표 대조), 지장간 표, 분일 경계, 통근(생조≠통근, 중복 원천), 십성 100개(만세력 엔진의 별도 구현과 교차), 간합, 실제 원국 재현성.
- **전문가 검증 전**: 테스트 통과는 "기준서대로 코딩됐다"는 뜻이지 명리학적으로 승인됐다는 뜻이 아니다.
