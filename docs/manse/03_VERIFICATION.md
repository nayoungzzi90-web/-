# 3. 검증 보고서 (만세력 엔진 v1.0.0)

> **결론 먼저**: 천문 절입 시각·음양력·4주·대운은 서로 독립인 구현 여러 개와 대조해 **일치함을 확인했다.** 그러나 **한국천문연구원(KASI) 공식 값과의 대조는 하지 못했다**(접속 불가). 따라서 이 엔진은 "공식 확인됨(`official_confirmed`)"을 단 한 건도 주장하지 않으며, `computation.verified` 는 항상 `false` 로 해석 엔진에 전달된다. 아래 숫자는 모두 이 저장소의 스크립트로 재현된다.

## 3.1 절입(24절기) 시각

| 검사 | 방법 | 결과 |
|---|---|---|
| 기준값 환산 vs 독립 구현 A | JPL DE421 자체 환산(`tools/ref/de421_events.py`) ↔ Swiss Ephemeris(Moshier), **TT 기준**(시간 척도 영향 제거) | 1900–2050 n=3,624 **최대 2.01초**(p99 1.61), 2051–2100 n=1,200 최대 2.25초 |
| 독립 구현 B | Astronomy Engine(MIT) | 최대 **56.1초**(p99 38) — 분 경계를 확정할 수 없어 **기준값으로 쓰지 않음**, 런타임 sanity(허용 90초)로만 기록 |
| UTC 환산 | 데이터의 UTC ↔ Swiss 로 독립 재계산한 UTC | 1972 이전 최대 2.00초(n=1,730), 1972–2026 최대 1.82초(n=1,320), **2027 이후 최대 25.4초**(n=1,800; 미래 윤초·ΔT 가정 차이) |
| 구조 | 1900–2100 매 해 24개, 시간순, 인접 간격 14~16.5일 | 통과 (vitest) |
| 문헌 sanity | 춘분 2000-03-20 07:35, 하지 2021-06-21 03:32, 동지 2021-12-21 15:59 UTC (±90초) | 통과 — **기억 기반이며 독립 증빙이 아님** |
| **KASI 공식 값** | — | **미수행** (접속 불가). `official_solar_terms` 적재 + `compareOfficial`/`refresh_solar_term_status` 로 비교하도록 도구와 시험은 준비됨(합성 fixture 시험만 통과) |

상태 모델: 모든 행은 `cross_checked`(독립 계산 일치) 이며 `official_confirmed` 는 0건이다(DB 시험에서 확인). 불확실도: ≤2026 ±5초, 2027–2050 ±30초, 2051+ ±60초. **출생 시각이 절입 시각과 (보호 구간 120초 + 불확실도) 안이면 연주·월주를 확정하지 않고 양쪽 후보를 모두 돌려준다.**

## 3.2 음양력 변환

- 방법: DE421 합삭(朔)을 시계(한국 역일)로 나눠 월 시작일을 정하고, 동지월~동지월 사이가 13개월이면 첫 무중기월을 윤달로 한다. 월 번호는 동지월(=11월)부터의 순서로 매긴다.
- 대조: `korean_lunar_calendar`(MIT, KASI 자료 기반 1000–2050) 와 **1900-01-01~2050-12-31 55,152일 전수** → **불일치 0건**. 윤달 56개(1900–2050)의 시작일·월 번호도 일치. 음→양 300건 표본 일치. 양→음→양 왕복 73,414일(1900–2100) 실패 0건.
- 검증 중 잡은 오류 2건: (1) 중기 이름으로 월 번호를 매기면 겨울에 한 달에 중기가 둘 든 해(1984–85, 2033)에서 어긋남 → 순서 기반 번호로 수정, (2) 한 달에 중기가 둘이면 첫 번째만 보던 버그(소설·동지) → 수정.
- **한계(중요)**: 1912년 이전은 대조 라이브러리의 결과에 맞추도록 "역일 경계를 UTC+8 로 본다"는 정책(`lunarClock=PRE1912_UTC_PLUS8`)을 **추정**했다(독립 라이브러리가 낸 월 시작일로부터 가능한 오프셋 범위를 역산). 이 구간은 대조가 **순환적**이라 독립 검증이 아니다. `TZDB_STANDARD` 로 바꿔 5개월(150일)이 달라짐을 확인했다. 1912–2050 은 정책을 맞춘 구간이 아니므로 **독립적인 일치**다. 2051–2100 음력은 대조할 독립 자료가 없다. DE421 계수 범위 이전의 1899-12 합삭 하나는 Astronomy Engine 값을 쓴다(자정에서 9시간 떨어져 날짜 판정에는 영향 없음).

## 3.3 4주 (연·월·일·시)

- `sxtwl`(BSD) 과 무작위 출생 20,000건(1900–2100, 시계는 입력 그대로 `ERA_WALL_CLOCK`): **일주·시주 20,000건 일치, 연주·월주 18,054건 일치**(절입 ±36시간 안 1,946건은 제외 — sxtwl 은 입력을 베이징시로 해석해 경계 부근 판단이 다를 수 있음).
- 두 라이브러리(`sxtwl`, `lunar_python`)가 모두 같은 값을 낸 83건 중 82건을 fixture 로 고정(자시 경계 22:59/23:00/23:59/00:00/00:59/01:00/02:59/03:00, 범위 양끝, 윤일, 서머타임 기간 등) → 엔진 일치. 나머지 1건(2050-05-05)은 두 라이브러리가 서로 달라 제외.
- 연주 기준(입춘/양력 1월 1일/음력설), 월주 오호둔, 시주 오서둔, 자시 세 정책의 진리표를 손으로 유도해 시험.

## 3.4 대운

- `lunar_python`(MIT) 대조(무작위 4,000건 중 절입 ±36시간 밖 3,618건): **순역 일치 3,618, 첫 3개 대운 간지 일치 3,618, 시작 나이(분 단위 환산·연 360일) 허용오차 0.004년 일치 3,618.** 시진 단위 방식(`SHICHEN`)은 23시를 마지막 시진으로 세는 상대 라이브러리 관행을 제외한 3,329건 일치.
- **대운 기산 차이는 설정으로 분리**: 시험 입력(1990-04-19 01:10 여)에서 `EXACT`=4세 6개월 14일, `DAYS_QUOTIENT`=4세 8개월, `SHICHEN`=별도 값, 연 길이 360 vs 365.2425 로 시작 시각이 달라짐을 시험으로 고정. 대운 간지 자체는 기산 정책과 무관.

## 3.5 시간대·서머타임

- `Asia/Seoul` 이력(LMT +8:27:52 → 1908 +8:30 → 1912 +9 → 1954 +8:30 → 1961 +9, ROK 서머타임 1948–51·1955–60·1987–88)을 IANA tz 원문에서 옮겼다. Node ICU(Intl)와 1908–2100 을 5시간 간격으로, 전환일 앞뒤 ±3일을 10분 간격으로 대조 → **불일치 0건**. 1987-05-10 02:30(공백)은 `NONEXISTENT_LOCAL_TIME`, 1987-10-11 02:30(중복)은 정책에 따라 FIRST/SECOND/ERROR.
- ICU 와 tz 는 같은 계보의 자료라 완전히 독립은 아니다. 1908년 이전 LMT 와 일제강점기 관련 세부는 tz 파일 주석도 불확실하다고 밝힌다.

## 3.6 DB (PGlite 위에서 실행)

`supabase/migrations/0005_solar_terms.sql` 을 PostgreSQL 호환 엔진(PGlite)에 적용하고 4,850행·9,674 검증 행·2,489 합삭을 적재해 시험: 연 24행·절 12개, 순서·간격, 제약(황경 15°배수, 연도 범위, 상태 값), 교차검증 실패 시 `cross_checked` 불가, 공식값 비교 함수(같은 분→confirmed, 1분 차→boundary_review, 2분 차→mismatch), RLS 정책 목록. **실제 Supabase 인스턴스에는 적용해 보지 않았다.**

## 3.8 아직 검증하지 못한 것 (확정하지 않는다)

1. KASI 공식 절입·음력과의 일치, 상업 이용 조건.
2. 지장간 표의 학파별 일수(외부 권위 자료로 대조 못 함), 합충형파해 표(널리 쓰이는 표를 사용; "작용 여부"는 판단하지 않음).
3. 2051년 이후 절입·음력, 미래 윤초.
4. 균시차 식은 근사(오차 ≈ 0.5분), 기본 정책에서는 꺼져 있음.
5. 1912년 이전 음력 역일 정책(추정), 1908년 이전 서울 지방평균시 해석.
6. 자시·진태양시·기산의 "기본 정책"은 임의 선택 — 서비스 정책으로 확정하려면 상담사/기획 결정이 필요.
7. 실제 Supabase 적용, 부하 시험, 보안 심사.
