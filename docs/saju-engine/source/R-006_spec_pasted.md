R-006 — 신강신약 종합 판단

규칙 ID: R-006
규칙 버전: R-006-DRAFT-1
상태: 사용자 승인 및 전문가 검증 대기
선행 규칙: R-001~R-005
기본 이론: 자평명리학 기반 종합 분석형
주요 참고 문헌: 《자평진전》, 《적천수천미》, 《삼명통회》

⸻

제1조. 목적

R-001~R-005의 결과를 종합하여 일간의 전체적인 강약 상태를 판단한다.

판단 과정에서 월령·통근·천간 지원·극설·소모·상호작용을 분석하고, 각 근거의 출처와 영향을 기록한다.

신강신약의 판단과 격국·조후·용신의 최종 판단을 분리한다.

제2조. 필수 입력 데이터

* 일간 및 원국의 네 기둥
* R-002의 월령·왕상휴수사 분석
* R-003의 지장간 및 사령 분석
* R-004의 구조적 통근 분석
* R-005의 천간 생조·극설·소모 분석
* 각 규칙의 버전과 검증 상태
* 계산 정책 및 절입 데이터 버전
* 출생 시각의 정확도

제3조. 판단 결과 구분

① 계절적 상태

일간의 월령 관계를 다음과 같이 기록한다.

* 旺
* 相
* 休
* 囚
* 死

이 값은 R-002에서 가져오며 신강신약 결과와 동일하게 취급하지 않는다.

② 구조적 지원 상태

일간의 본기근·비본기근·천간 인성·비겁과 관련된 근거를 기록한다.

③ 구조적 제약 상태

식상·재성·관살의 관계와 해당 요소들의 통근·상호작용을 기록한다.

④ 종합 판단 상태

* strong: 신강
* weak: 신약
* balanced: 중화
* undetermined: 판단 유보
* special_review: 특수격 검토 필요

실제 운영에서는 승인된 판단 규칙을 통과한 경우에만 strong, weak, balanced를 확정할 수 있다.

제4조. 계절적 영향 분석

R-002의 seasonal_grade를 사용한다.

旺과 相은 계절적 지원의 양상이 다르므로 동일한 판정으로 합치지 않는다.

특히 相에 해당하는 경우 월령의 생조가 존재하더라도 일간 자체가 직접 당령한 것으로 간주하지 않는다.

休·囚·死를 각각 구분하여 해석한다.

辰·未·戌·丑월은 R-002의 토월 잠정 판정과 R-003의 사령 분일 검증 상태를 확인한다.

이견이 실제 종합 강약을 변경할 수 있는 경우 최종 판정을 유보한다.

제5조. 통근 근거 분석

R-004에서 확인한 구조적 통근을 다음 요소로 구분한다.

1. 본기근 존재
2. 비본기근 존재
3. 일지 통근
4. 월지 통근
5. 년지·시지 통근
6. 여러 지지에 걸친 통근
7. 동일 천간 근과 동일 오행 근의 차이

구조적 뿌리의 존재는 확정 사실로 기록한다.

그러나 통근의 개수만으로 실제 작용력이나 신강신약을 결정하지 않는다.

고전의 장생·녹왕·묘고 등 확장 근기 분석 결과가 필요한 경우 별도 검토 대상으로 기록한다.

제6조. 지지의 인성 지원 분석

구조적 통근과 구분하여 지장간의 인성도 검토한다.

지장간에 일간을 생하는 오행이 존재하면 인성의 잠재적 지원 관계로 기록한다.

단, 지장간 인성의 존재를 일간의 직접 통근으로 계산하지 않는다.

해당 인성이 실제로 어느 정도 작용하는지는 월령·위치·상호작용 및 후속 규칙을 함께 검토한다.

제7조. 천간 지원·제약 분석

R-005의 결과를 이용한다.

다음 데이터를 구분한다.

* 비겁 지원 후보
* 인성 생조 후보
* 식상 설기 관계
* 재성 소모 관계
* 관살 극제 관계

각 천간의 통근과 주변 상호작용을 참조한다.

지원 또는 제약 관계의 단순 개수를 실제 힘으로 취급하지 않는다.

제8조. 중복 근거 방지

하나의 원천 지지 또는 지장간에서 발생한 관련 근거를 별도 식별자로 연결한다.

예를 들어 갑목이 인월에 태어났을 때:

* R-002는 인월의 계절적 지원을 기록한다.
* R-004는 인목의 갑목 통근을 기록한다.

두 결과는 모두 유효하지만 같은 인목에서 발생한 근거라는 사실을 저장한다.

최종 분석에서는 이를 서로 완전히 독립적인 두 개의 강한 근거처럼 단순 합산하지 않는다.

제9조. 상호작용에 따른 검토

다음 관계가 계산 결과를 수정할 수 있는지 검토한다.

* 천간 간합 및 합화
* 천간의 상호 극제
* 지지의 충·형·파·해
* 삼합·방합 등의 결합 구조
* 인성의 제약
* 식신제살 및 살인상생의 경쟁 구조
* 재생관·관인상생 등의 연결

관계 후보와 실제 작용의 성립 여부를 구분한다.

성립하지 않았거나 아직 검증하지 않은 관계를 임의로 적용하지 않는다.

제10조. 특수 구조 선행 검사

종재·종관살·종아·종왕·종강·종세·가종 등 특수 구조의 가능성을 검토한다.

해당 후보가 발견되고 일반 강약 판정에 영향을 줄 수 있는 경우 special_review로 처리한다.

종격·가종격의 성립은 별도 승인된 규칙에 따르며 R-006이 임의로 확정하지 않는다.

제11조. 일반 강약 판단

특수 구조가 아닌 경우 다음을 검토한다.

1. 계절적 지원의 유무와 성격
2. 일간이 확보한 뿌리의 구조
3. 인성·비겁의 지원 관계
4. 식상·재성·관살의 제약 관계
5. 각 요소의 통근 및 상호작용
6. 근거 사이의 충돌
7. 분석에 영향을 주는 미확정 조건

판단 근거가 일관되게 신강 방향을 지지하면 strong 후보로 기록한다.

일관되게 신약 방향을 지지하면 weak 후보로 기록한다.

균형을 뒷받침하는 승인된 규칙이 있는 경우에만 balanced를 허용한다.

조건이 부족하거나 서로 충돌하면 undetermined로 기록한다.

제12조. 확정과 잠정 판단의 분리

판단 결과를 다음 상태로 구분한다.

* candidate: 자동 생성된 판단 후보
* approved: 승인된 판단 규칙으로 확정한 결과
* review_required: 추가 검토가 필요한 결과
* blocked: 계산 오류 또는 필수 데이터 부재

초기 개발에서는 자동 생성된 판단 후보를 확정 결과처럼 표시하지 않는다.

승인된 규칙 및 테스트를 모두 통과한 경우에만 자동 확정할 수 있다.

제13조. 용신 선정과의 분리

R-006은 신강신약을 판단하는 모듈이며 용신을 직접 선정하지 않는다.

격국론 용신, 억부론 용신 후보, 조후론 용신 후보는 각각 별도의 분석 모듈에서 생성한다.

세 분석 결과가 서로 다르면 출처와 해석 체계를 함께 저장한다.

AI는 차이를 임의로 제거하거나 하나의 결론으로 조작하지 않는다.

제14조. 판단 유보 조건

다음 상황에서 확정 판단을 제한한다.

1. 필수 만세력 계산값의 오류 또는 누락
2. 출생 시각 불확실성으로 원국이 달라질 수 있음
3. 절입 경계 문제 미해결
4. 토월 사령 분일의 이견이 결과에 영향을 줄 수 있음
5. 확장 근기 분석 결과가 결정적으로 중요한 경우
6. 합충·합화에 따라 세력 구조가 크게 달라질 가능성
7. 종격·가종격 후보 미해결
8. 강약 근거가 충돌하고 우선순위 규칙이 없음
9. 해당 원국에 적용할 검증된 종합 판단 규칙이 없음

단순히 해석이 어렵다는 이유로 억지로 중화 판정을 내려서는 안 된다.

제15조. AI 해석 제한

AI는 계산 사실과 승인된 판단을 변경할 수 없다.

신강·신약을 성격의 우열, 건강 상태, 재물 규모, 결혼 가능성 등과 직접 연결해 단정하지 않는다.

판단 근거와 예외 사항을 설명하고, 결과의 확실성 수준을 구분한다.

판단이 유보된 경우 AI는 새로운 결론을 추측하지 않는다.

제16조. 저장 및 감사 추적

다음 데이터를 기록한다.

* 원국 계산 ID
* R-001~R-005 규칙 버전
* 계절·통근·천간 관계 근거
* 증거의 원천 식별자
* 강약 후보 및 최종 판정
* 특수 구조 검토 결과
* 충돌·유보 사유
* 사용된 고전 문헌과 해석 규칙 ID
* 전문가 승인 이력
* 계산 및 AI 모델 버전

제17조. 완료 조건

* 일반 강약 후보 판정 규칙 구현
* 종격 및 예외 후보 우선 탐지
* 판단 유보 조건 구현
* 중복 근거 연결
* R-002~R-005 데이터 연동
* 전체 테스트 사례 통과
* 전문가 검수 및 이견 기록
* 반복 호출 시 동일한 구조적 판단
* AI가 미승인 판단을 확정하지 않는지 검증

R-006은 근거가 부족한 상황에서 결론을 만들어내지 않는 것을 품질 기준에 포함한다.
