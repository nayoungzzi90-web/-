오행 친구들 명리학 해석 기준서 v1.0

R-003 — 월령 지장간과 인원사령 분일 분석

규칙 버전: R-003-DRAFT-1
상태: 검토 중
선행 규칙: R-001, R-002
채택 체계: 자평명리학 종합 분석형

제1조. 목적

지지에 배속된 지장간의 구성과 월내의 사령 분일을 구분하여 계산한다.

계산 결과는 향후 격국, 통근, 신강신약, 용신 분석의 근거 자료로 제공한다.

제2조. 고정 지장간 규칙

기본 지장간 데이터는 《연해자평》의 지지장둔가에 따른 다음 구성을 채택한다.

지지	지장간	본기
子	癸	癸
丑	己·癸·辛	己
寅	甲·丙·戊	甲
卯	乙	乙
辰	戊·乙·癸	戊
巳	丙·庚·戊	丙
午	丁·己	丁
未	己·丁·乙	己
申	庚·壬·戊	庚
酉	辛	辛
戌	戊·辛·丁	戊
亥	壬·甲	壬

위 목록은 구성원과 본기를 확정하는 정적 데이터다.

표의 나열 순서는 사령하는 시간 순서를 의미하지 않는다.

중기·여기·묘고 성격의 상세 명칭은 분류 체계별로 별도 관리한다.

제3조. 사령 분일 규칙집

두 가지 규칙집을 독립적으로 저장한다.

* SMTH_30_V1: 《삼명통회》 권2 원문 분일표
* MODERN_30_CANDIDATE_V1: 현대 통용 분일표 채택 후보

두 규칙집은 서로의 값을 덮어쓰지 않는다.

원전의 艮土, 坤土 등은 원문 표기를 보존하고, 확인되지 않은 천간 치환은 수행하지 않는다.

운영용 후보 규칙집의 원문, 일수, 해석상의 이견을 전문가가 검토하여 승인한다.

제4조. 필수 입력

* 검증된 출생 시각
* 출생 시각의 시간대
* R-001에서 확정한 월지
* 해당 월의 절입 시작 시각
* 다음 월의 절입 시작 시각
* R-001 계산 정책 버전
* R-003 사령 분일 규칙집 버전

절입 구간이 검증되지 않으면 계산을 중단한다.

제5조. 분일 시간 환산

전통적인 30일 분배를 실제 절입 구간에 적용하는 과정은 별도의 현대적 계산 정책으로 명시한다.

초기 권장 정책은 normalized_30_v1이다.

1. 해당 월의 시작 절입 시각을 S로 정의한다.
2. 다음 월의 시작 절입 시각을 E로 정의한다.
3. 출생 시각을 B로 정의한다.
4. 월내 위치를 p = (B-S)/(E-S)로 계산한다.
5. 분일표의 누적 일수를 30으로 나눈 비율과 p를 비교한다.
6. 해당 구간의 사령 천간을 반환한다.

이 방식은 전통 분일표의 구간 비율을 현대의 실제 절입 간격에 맞게 비례 배분하는 오행 친구들의 계산 정책이다.

고전이 직접 규정한 초 단위 분일법이라고 주장하지 않는다.

시간 환산 알고리즘 역시 버전 관리한다.

제6조. 경계 조건

* 출생 시각이 시작 절입과 정확히 같으면 새 월의 첫 구간에 포함한다.
* 출생 시각이 다음 절입과 정확히 같으면 다음 월로 넘긴다.
* 각 구간은 시작 시각을 포함하고 종료 시각은 포함하지 않는다.
* 월내 분일 경계와 정확히 같으면 새 구간에 포함한다.
* 출생 시각이 불확실하고 가능한 구간이 여러 개면 단일 사령을 확정하지 않는다.

제7조. 이견 처리

A형과 B형에서 계산된 사령 천간이 다르면 다음 정보를 보존한다.

* 각 규칙집의 사령 결과
* 원문 출처와 버전
* 결과 차이 여부
* 차이가 발생한 원인
* 후속 해석에서 활용 가능한 범위

미검증 비교 결과를 이용해 종합 신강신약이나 용신을 확정하지 않는다.

제8조. 명리학적 해석 제한

* 월지의 본기와 월내 사령 천간을 혼동하지 않는다.
* 사령 천간 하나로 격국을 자동 결정하지 않는다.
* 월령의 도움과 통근을 동일한 요소로 취급하지 않는다.
* 월령의 계절 기운과 조후상 적합성을 구분한다.
* 동일한 근거를 여러 분석 단계에서 무분별하게 중복 가산하지 않는다.
* 사령 구간 차이로 인생의 사건이나 길흉을 단정하지 않는다.

제9조. 후속 규칙과의 연결

R-003에서 생성한 데이터는 향후 다음 모듈에 전달한다.

* R-004: 통근 및 득지 분석
* R-005: 천간 생조와 극설 분석
* R-006: 신강신약 종합 판단
* 격국 분석 규칙
* 조후·통관·병약 분석 규칙

이때 사령 정보는 하나의 분석 근거이며, 자동적인 최종 결정권을 갖지 않는다.

제10조. AI 출력 정책

AI는 사령 천간을 재계산하거나 수정할 수 없다.

AI는 승인된 해석 결과를 바탕으로 다음을 구분해 서술한다.

1. 계산으로 확정한 사실
2. 채택한 명리학 이론에 따른 해석
3. 다른 규칙집과의 차이
4. 추가 분석이 필요한 부분

전문가 검증이 끝나지 않은 항목은 유료 상담문에서도 임의로 확정하지 않는다.

제11조. 검증과 기록

각 결과에 다음 정보를 보존한다.

* 사령 규칙집 ID
* 분일 계산 정책 ID
* 출생 시각 및 월 절입 경계
* 원문 천간과 정규화된 천간
* 월내 위치와 선택된 사령 구간
* 규칙별 비교 결과
* 승인·미승인 상태
* 계산 엔진 버전 및 생성 시각

제12조. 승인 조건

* 12개 월지의 정적 지장간 검증
* 두 분일표의 원문 대조와 버전 기록
* 각 월의 분일 합계 30 확인
* 시간 환산 경계 테스트 통과
* 출생 시각 불확실성 처리 확인
* 동일 입력·동일 버전에서 동일 결과 생성
* 두 규칙집의 결과 차이 기록
* 사령 결과에 따른 격국·용신의 무근거 확정 방지

R-003은 사령의 계산 규칙을 확정하는 단계이며, 사령의 해석상 영향력이나 가중치를 확정하는 단계가 아니다.
