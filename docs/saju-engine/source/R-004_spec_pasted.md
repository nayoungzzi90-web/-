R-004 — 통근 및 득지 분석

규칙 버전: R-004-DRAFT-1
상태: 검토 중
선행 규칙: R-001·R-002·R-003
분석 체계: 자평명리학 기반 종합 분석형

제1조. 목적

일간을 비롯한 네 천간이 사주의 네 지지에 뿌리를 두고 있는지 분석한다.

통근의 존재, 지장간의 유형, 천간과 지장간의 오행·음양 관계, 통근 위치를 개별 데이터로 저장한다.

통근의 실질적 강약과 최종 신강신약은 본 규칙에서 확정하지 않는다.

제2조. 입력 데이터

* R-001에서 확정한 연주·월주·일주·시주
* 10천간의 오행 및 음양 대응표
* R-003에서 채택한 정적 지장간 구성표
* 지장간별 본기·중기·여기 분류 정책
* R-002의 월령 분석 결과
* 규칙 및 원천 데이터 버전

R-003의 지장간 세부 분류가 미승인된 경우 중기근과 여기근을 추정하지 않고 classification_pending으로 기록한다.

제3조. 기본 통근 판정

각 천간에 대해 네 지지의 모든 지장간을 탐색한다.

① 동일 천간 통근

천간과 지장간이 정확히 같으면 exact_stem으로 기록한다.

② 동일 오행 통근

천간과 지장간의 오행이 같으나 음양이 다르면 same_element로 기록한다.

③ 비통근

해당 지지의 정적 지장간에 동일 오행이 없다면 no_structural_root로 기록한다.

생조 관계만 존재하는 지지는 구조적 통근으로 기록하지 않는다.

제4조. 근의 층위 구분

지장간이 해당 지지의 본기이면 main_qi로 기록한다.

본기가 아닌 경우 secondary_qi로 기록한다.

중기와 여기의 세부 구분은 승인된 분류 데이터가 존재하는 경우에만 추가한다.

묘고·여기·장생 등 고전적 근기 구분은 별도 속성으로 보존하며, 정적 지장간의 존재 여부와 혼합하지 않는다.

제5조. 통근 위치 판정

통근이 나타나는 지지의 위치를 다음과 같이 저장한다.

* year_branch: 년지
* month_branch: 월지
* day_branch: 일지
* hour_branch: 시지

일간이 일지에 통근하는 경우 day_branch_rooted = true로 기록한다.

일간이 월지에 통근하는 경우 month_branch_rooted = true로 기록한다.

day_branch_rooted는 일지 통근을 의미하는 명시적 데이터이며, 모든 명리학 학파의 득지 정의와 동일하다고 주장하지 않는다.

제6조. 다중 통근

하나의 천간이 여러 지지에 뿌리를 두면 각각 독립적인 근거로 기록한다.

동일 지지의 동일 지장간이 여러 천간과 연결되더라도, 원천 지장간은 하나로 식별한다.

여러 개의 뿌리가 있다는 사실만으로 특정 강약 등급을 자동 부여하지 않는다.

제7조. 월령·사령과의 관계

R-002의 계절적 지원은 통근 판정과 별도로 저장한다.

R-003의 사령 결과는 월지의 추가 참고 정보로 연결한다.

사령 천간이 정적 지장간에 없다는 이유로 지장간표를 임의 수정하거나 새로운 구조적 뿌리를 생성하지 않는다.

월지 통근과 계절 지원은 최종 강약 판단 시 중복 평가 여부를 검토해야 한다.

제8조. 합충형파해에 대한 처리

통근을 계산할 때 원국의 정적 지장간을 자동 삭제하지 않는다.

합충형파해, 삼합·방합, 합화 성립 여부 등은 별도의 검증 규칙에서 분석한다.

이러한 관계에 따른 뿌리의 작용 변화는 root_modification = not_evaluated로 기록한다.

제9조. 확장 근기 분석

전통적으로 사용하는 장생·건록·제왕·묘고·여기의 관계는 별도 확장 모듈에서 검토한다.

확장 근기 분석은 정적 지장간의 동일 오행 검색을 대체하지 않는다.

고전 해석에 따라 결과가 다를 때는 원문과 이론 체계를 기록한다.

제10조. AI 해석 제한

AI는 검증된 통근 데이터를 임의 수정할 수 없다.

일지 통근만으로 독립성, 재물운, 직업 적성, 결혼운 등을 확정할 수 없다.

통근이 없다는 이유만으로 일간이 신약하다고 단정하지 않는다.

통근이 여러 개라는 이유만으로 일간이 신강하다고 단정하지 않는다.

모든 상담문은 계산 사실과 해석상 추론을 구분해야 한다.

제11조. 결과 데이터

최소한 다음 정보를 반환한다.

* 분석 대상 천간 및 위치
* 통근한 지지 및 위치
* 근거 지장간
* 동일 천간/동일 오행 구분
* 본기/비본기 구분
* 일지 통근 여부
* 월지 통근 여부
* 전체 구조적 통근 유무
* 확장 근기 분석 상태
* 합충 등 수정 요인 검토 상태
* 원천 자료와 규칙 버전

제12조. 품질 검증

1. 10천간 × 12지지의 120개 구조적 조합 검증
2. 네 천간 × 네 지지의 전체 탐색 확인
3. 정적 지장간표와 사령 분일표의 혼동 방지
4. 본기근·비본기근 구분 확인
5. 동일 천간과 동일 오행의 구분 확인
6. 일지 및 월지 통근 플래그 검증
7. 동일 지장간의 중복 가산 방지
8. 생조 관계의 통근 오판 방지
9. 합충에 따른 정적 지장간 자동 삭제 방지
10. 통근만으로 신강신약을 결정하지 않는지 확인

R-004의 완료 기준: 모든 구조적 통근 테스트 통과, 지장간 분류 검증 완료, 해석 제한 규칙 적용 및 명리학 검토 완료.
