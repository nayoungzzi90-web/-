# 오행 친구들 — R-001~R-015 복원 통합 마스터 기준서

작성일: 2026-10-29

## 복원 상태 및 신뢰 경계

이 문서는 실제 보관된 과거 문서를 **원문 그대로** 결합하고, 원문이 발견되지 않은 단계는 이전 사용자 채택 정책을 바탕으로 **요약 복원**한 자료다. 전체 15개 세부 원문이 모두 확보됐다는 의미가 아니다. 문헌과 소스 구현의 승인 상태를 혼동하지 않는다.

- **원문 확보:** R-001 구현·검증 보고서, R-010~R-015 상세 명세서. 단 이 문서들에도 DRAFT/미검증 항목이 있으며 최종 운영 승인 상태가 아니다.
- **원문 미확보:** R-002~R-009의 개별 상세 원문. R-008/009 TypeScript 참조 소스는 별도 ZIP의 R-015 전체감사 번들에 보관되어 있다.
- **정책 복원:** R-002~R-005의 이전 사용자 채택 원칙 및 R-006~R-009의 요약된 방향. 이 부분은 세부 수학·시간 경계·예외 알고리즘을 새로 지어내지 않는다.
- **운영 상태:** R-015 원본 문서는 NO_GO. 승인된 *정책*과 운영 출시 허가는 다르다.

## Claude Code에 대한 최우선 지시

1. 기존 프로젝트와 이 문서 및 동봉 원본 명세들을 읽고 충돌·누락·구현 상태를 분리하여 감사한다.
2. 원문 확보 섹션은 그대로 추적하고, DRAFT/NO_GO/미검증 상태를 임의로 APPROVED로 바꾸지 않는다.
3. 상세 원문이 없는 R-002~R-009는 `SOURCE_MISSING`으로 분류하고, 참조 코드가 있는 경우에도 문서 완전 복원을 주장하지 않는다.
4. 구현 전 분석 보고서를 제공한다. 기존 코드 및 DB, API 키, 결제 로직은 승인 없이 수정하지 않는다.
5. GPT는 규칙 기반 판단 데이터의 상담문 생성자, Gemini는 독립 분석·감수자. 두 모델 모두 원국·격국·용신 최종 판정 권한 없음.
6. 서버 측 API 연결과 JSON 스키마 검증, evidence_id 계보, 미승인 claim 발행 차단을 설계한다.
7. R-015의 Gate0~6 및 C01~C18, NO-GO/LIMITED-GO/GO 정책을 보존한다.

## 복원된 의존 그래프

입력→ R001 → {R002,R003,R005} → R004 → R006(초기) → R007/R008 → R009(특수격 후보) → R006(재평가) → R010 → {R011,R012,R013} → R014 → R015.

정확한 선후 의존성은 아래 R-015 원문을 우선한다. R-006 ↔ R-009는 무한 순환 호출이 아니라 제한된 상태 전이로 다룬다.


# R-002~R-009 채택 정책 복원(상세 원문 미확보)

**주의:** 이 섹션은 이전 대화에서 확인된 채택 정책의 복원본이며, 세부 소스 텍스트를 재현한 문서가 아니다. 각 단계의 원본 규칙표·전수 예외·실제 구현 테스트 조건은 `SOURCE_MISSING` 또는 `IMPLEMENTATION_REVIEW_REQUIRED`로 관리한다.

## R-002 월령·계절 세력
- 월령과 계절이 오행에 미치는 영향을 계산 사실 및 질적 관계로 기록한다.
- 일간의 득령/旺相과 원국 전체의 최종 신강·신약은 별개다. 월령만으로 강약을 확정하지 않는다.
- `월령 계절 영향` 및 `실제 세력`을 별도 데이터로 표현한다.
- **미복원:** 월령별 구체 판정표, 예외 조건, 승인된 출력 스키마.

## R-003 지장간·사령 분일
- **고정 지장간 표:** 《연해자평》 기반 출처 관리.
- **사령 분일:** B형 분일표를 기본 *후보*로 두고 A형 《삼명통회》와 비교한다.
- 절입 시각 이후 경과시간 비례배분을 활용한다. 달력 날짜만으로 경계 계산하지 않는다.
- B형 미검증 구간은 전문가 검증 전 계산 사실로 승격 금지. 분일표 버전·이견을 기록한다.
- 사령 하나만으로 격국·용신 확정 금지. 고정 지장간과 사령 분일을 서로 다른 출처와 버전으로 유지.
- **미복원:** B형 전 구간 분일 수치, A/B 분일 비교표, 경계 테스트의 완전 원문.

## R-004 구조적 통근·득지
- 통근은 천간과 지장간 간 **구조적 존재**로 기록한다. 단순 생조(예: 水生木)는 통근이 아니다.
- 본기근/중기근/여기근과 정확 천간 일치/동오행 관계를 분리한다.
- 합·충 존재만으로 통근 자동 삭제 금지. 합충의 작용 가능성/실제 성립 구분.
- 통근 개수의 임의 점수화 금지.
- **미복원:** 12지지별 상세 강도/위치 우선순위 원문, 확정 효력 판정 알고리즘.

## R-005 천간 생극·합화·구조 후보 (DRAFT-2 채택)
- 상대 천간의 생조, 극설, 소모 및 득세를 위치·거리와 **여섯 쌍의 천간 관계**를 고려해 기록.
- 일간 자신을 네 천간에 포함된 또 하나의 별도 비견으로 중복 계수하지 않음.
- 간합 후보와 합화 성립을 구분하고, 합화 조건 미검증 시 확정 금지.
- 살인상생·식신제살·재극인 등은 구조적 후보를 탐지하되 실제 성립과 유불리는 유보.
- **미복원:** 거리/위치 간 정확 알고리즘, 여섯 쌍 매핑 세부표, 각 구조의 승인된 완전 성립 조건.

## R-006 신강·신약·중화
- 득령·통근·천간 관계를 질적으로 종합, 증거와 반증을 함께 기록.
- 일반 강약의 1차 후보 판단 → R-009 특수격 후보 검토 → R-006의 한정된 재평가(상태/버전 추가).
- 종격 미해결 시 일반 억부의 최종 확정 차단. 임의 점수 합산 금지.
- **미복원:** 신강/신약/중화 최종 경계와 이견 해소의 구체 규칙, 테스트 원문.

## R-007 기본 격국 후보
- 월령 및 지장간·투출 등 구조에 따라 격국 후보를 만든다.
- 월지 본기 후보를 최종 격국으로 자동 확정하지 않는다; R-010 서명 전 `final_geju = null`.
- **미복원:** 기본격 취격 분기·예외의 전체 원문.

## R-008 투간·회합·잡기 후보
- R-001/R-003/R-007이 검증한 원국을 입력으로 받은 후보 탐지기.
- 지장간의 **동일 천간 투출(exact)**, **동오행 노출(related)**, **합화(transformation)**를 분리.
- 辰戌丑未 잡기, 회합, 격국 성립 가능성을 기록하되 최종 취격이나 합화 성립을 주장하지 않는다.
- 참조 코드: `UPSTREAM_R008_R014/oheng_r008.ts` (동봉 감사 ZIP).
- **미복원:** 사용자 승인 상세 기준서 원문. 코드 ≠ 승인된 명리 정책.

## R-009 특수격 후보
- 참조 코드가 다루는 후보: 建祿, 月劫, 羊刃, 從財, 從官, 從兒, 從勢, 從强, 從混, 假從 재검토.
- 후보 탐지만 수행하며 `status: review_required`, `final_pattern: null`, `final_follow_status: not_evaluated`를 유지.
- 甲卯의 월겁·양인 중첩 등 복수 후보를 하나로 임의 삭제하지 않는다.
- 참조 코드: `UPSTREAM_R008_R014/oheng_r009.ts` (동봉 감사 ZIP).
- **미복원:** 특수격 승인 성립/파격 전수 조건·예외의 원문.
