# R-003 사령 분일표 — 후보(UNVERIFIED)

**이 파일은 기준서 원문이 아니다.** R-003 원문은 두 규칙집(`SMTH_30_V1`: 《삼명통회》 권2 원문 분일표, `MODERN_30_CANDIDATE_V1`: 현대 통용 분일표 후보)의 **이름과 계산 방식만** 정하고 분일 수치표는 싣지 않았다. 사용자 요청("추천대로")에 따라, 이 저장소 만세력 엔진(`engine/manse/src/hidden.ts`)이 쓰는 널리 알려진 월률분야 표를 `MODERN_30_CANDIDATE_V1` 후보로 옮겨 적는다.

## 상태
| 규칙집 | 상태 |
|---|---|
| `SMTH_30_V1` (《삼명통회》 권2) | **MISSING** — 원문 수치를 확인한 자료가 없다. 기억으로 적지 않는다(출처 조작 금지). 원문 사진·텍스트가 필요하다. |
| `MODERN_30_CANDIDATE_V1` | **UNVERIFIED 후보** — 엔진 코드 주석에도 "외부 권위 자료로 검증하지 못했다"고 적혀 있다. 전문가 확인 전에는 사용자 결과에 쓰지 않는다. |

## R-003 정적 지장간(《연해자평》)과의 차이 (사실)
R-003 원문은 정적 지장간(고정 구성)과 사령 분일을 **서로 다른 데이터**로 두라고 한다. 위 분일표의 일부 사령 천간은 정적 지장간에 없다(子 壬, 卯 甲, 酉 庚, 午 丙, 亥 戊). R-003 제3조·R-004 제7조가 말하듯 "사령 천간이 정적 지장간에 없다는 이유로 지장간표를 바꾸거나 새 뿌리를 만들지 않는다".

## 사용 규칙
- 시간 환산은 R-003의 `normalized_30_v1`(월내 위치 p = (B−S)/(E−S), 구간 경계는 시작 포함·종료 미포함)을 쓴다.
- 이 후보와 `SMTH_30_V1`의 결과가 다르면 차이를 그대로 기록하고 사령만으로 격국·용신을 정하지 않는다.
- **현재 AI 풀이는 사령을 쓰지 않는다.** 사용자 결과에 사령이 필요한 해석은 만들지 않는다.
