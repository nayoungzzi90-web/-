R-007 — 월령 기반 기본 격국 판정

규칙 버전: R-007-DRAFT-1
상태: 사용자 승인 및 구현 검증 대기
이론 체계: 자평명리학 기반 종합 분석형
선행 규칙: R-001, R-003, R-005
참고 규칙: R-002, R-004, R-006

제1조. 목적

일간과 월지 본기의 십성을 계산하여 기본 격국 후보를 생성한다.

건록·월겁·양인 및 잡기월에 해당하는 경우 일반적인 십성 격국과 구분해 후속 검토 대상으로 지정한다.

이 단계에서는 격국의 최종 성립·성패·용신을 확정하지 않는다.

제2조. 필수 입력

* 일간
* 월지
* R-003에서 검증한 정적 지장간 및 본기
* R-005에서 확정한 십성 계산 규칙
* R-001의 월주 계산 정책 및 결과
* 적용 규칙 버전

R-003의 월내 사령 천간은 본기와 분리해 저장하며, R-007의 기본 격국 판정에 본기를 대신해 사용하지 않는다.

제3조. 월지 본기

기본 지장간 데이터는 R-003을 따른다.

寅	甲
卯	乙
辰	戊
巳	丙
午	丁

申	庚
酉	辛

본기 정보는 정적 데이터로 관리한다.

출생일이 월내에서 이동하더라도 월지 본기는 변경하지 않는다.

제4조. 일반 격국 후보

본기의 십성이 다음에 해당하면 대응하는 격국 후보를 생성한다.

* 정관 → 정관격 후보
* 편관 → 편관격 후보
* 정재 → 정재격 후보
* 편재 → 편재격 후보
* 정인 → 정인격 후보
* 편인 → 편인격 후보
* 식신 → 식신격 후보
* 상관 → 상관격 후보

비견·겁재는 일반적인 십성 격국으로 자동 확정하지 않는다.

제5조. 건록 판정

일간별 건록 월지 매핑표를 적용한다.

甲寅, 乙卯, 丙巳, 丁午, 戊巳, 己午, 庚申, 辛酉, 壬亥, 癸子를 건록 후보로 기록한다.

건록격의 실제 활용 구조는 R-009에서 검토한다.

제6조. 양인 판정

초기 채택 정책에서는 오양간의 월령 양인만 탐지한다.

* 甲卯
* 丙午
* 戊午
* 庚酉
* 壬子

양인 후보는 월지 본기의 십성이 비견·겁재·인성 등 무엇이든 독립적으로 기록한다.

양인격의 성립과 관살의 제어 조건은 R-009~R-010에서 검토한다.

음간 양인 및 다른 신살 계열의 양인 규칙은 본 엔진에서 자동 적용하지 않는다.

제7조. 월겁 판정

월지 본기가 일간의 겁재이면 월겁 검토 후보를 생성한다.

다만 양인 조건에 해당하면 양인 후보를 우선 표시한다.

진술축미 잡기월에서는 잡기 취격 검토를 우선한다.

월겁 후보의 실제 취격과 재관살식 활용 조건은 R-009에서 확정한다.

제8조. 잡기월 판정

월지가 辰·戌·丑·未에 해당하면 mixed_qi_review = true를 설정한다.

이때 본기 십성은 그대로 계산한다.

그러나 본기 십성만으로 최종 격국을 확정하지 않는다.

R-008에서 지장간 투출, 회합, 격국 변화, 고전 잡기 취격 규칙을 추가 검토한다.

제9조. 복수 후보 처리

하나의 원국이 여러 후보 조건에 해당할 수 있다.

예를 들어 戊일간·午월의 경우 다음을 모두 저장한다.

* 본기 丁에 따른 정인 관계
* 양인 해당 여부
* 양인과 인성 사이의 향후 구조적 검토 필요성

두 관계 중 하나를 임의로 삭제하지 않는다.

최종 격국은 후속 규칙에서 확정한다.

제10조. 투간·회합의 분리

월지 지장간의 천간 투출은 R-008에서 검사한다.

월지와 다른 지지의 회합 후보 역시 R-008에서 검사한다.

R-007은 이러한 변화 조건을 독자적으로 확정하지 않는다.

제11조. 출력 데이터

다음 항목을 필수 출력한다.

* rule_id
* rule_version
* day_stem
* month_branch
* month_main_stem
* main_ten_god
* base_pattern_candidate
* special_pattern_candidates
* mixed_qi_review
* primary_review_route
* final_pattern
* status
* evidence_ids
* source_policy_version

기본 격국 후보와 최종 격국은 다른 필드로 관리한다.

제12조. 판단 제한

다음 행위를 금지한다.

1. 본기 십성만으로 격국 성립 확정
2. 사령 천간을 본기처럼 사용
3. 비견·겁재를 일괄적으로 일반 정격으로 처리
4. 건록과 양인의 누락
5. 진술축미월의 잡기 검토 생략
6. 양인 후보를 겁재 후보에 덮어쓰기
7. 격국의 성립만으로 신강신약 자동 확정
8. 기본 격국만으로 용신·희신·기신 확정
9. 격국 이름만으로 재물운·연애운·직업운 단정

제13조. 완료 조건

* 10일간 × 12월지의 120개 기본 조합 계산
* 모든 본기 십성 계산 검증
* 건록 10개 매핑 검증
* 오양간 양인 5개 매핑 검증
* 월겁 및 잡기월의 예외 처리 검증
* 복수 후보의 보존 확인
* R-003 사령과 월지 본기의 혼동 방지
* 동일 입력과 규칙 버전의 동일 결과 생성
* 최종 격국의 조기 확정 방지
* 전문가 검수 완료

R-007은 기본 격국 후보를 생성하는 계산 규칙이며, 격국 전체의 성립 여부를 최종 판정하는 규칙이 아니다.
