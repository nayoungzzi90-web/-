오행 친구들 명리학 해석 기준서 v1.0

격국·용신 종합 분석 엔진

문서 버전: GY-ENGINE-DRAFT-1
상태: 사용자 승인 및 전문가 검증 대기
선행 규칙: R-001R-006
개발 규칙: R-007R-014
이론 체계: 자평명리학 기반 종합 분석형

제1조. 기본 목적

격국·용신 분석 엔진은 월령을 중심으로 사주의 구조를 분석하고, 격국론·억부론·조후론·통관론·병약론의 결과를 구분하여 생성한다.

최종적으로 각 분석의 계산 근거, 적용 이론, 판단 상태, 해석상 이견을 기록한다.

제2조. 격국 판단

R-007: 월령 기반 기본 격국

1. 일간과 월지의 본기 관계를 계산한다.
2. 십성에 따라 기본 격국 후보를 생성한다.
3. 건록·월겁·양인에 해당할 가능성이 있으면 별도 후보로 분류한다.
4. 기본 격국 후보를 최종 격국으로 자동 확정하지 않는다.

R-008: 격국 변화 및 잡기

1. 월지 지장간의 천간 투출을 분석한다.
2. 월지와 관련된 지지 회합 후보를 확인한다.
3. 여러 지장간이 투출하면 각각의 후보를 저장한다.
4. 진술축미월은 잡기 취격 규칙을 적용한다.
5. 월내 사령 정보는 별도 근거로 기록한다.
6. 회합·합화의 작용이 검증되지 않았다면 격국 변화를 확정하지 않는다.

R-009: 특수 구조

1. 건록·월겁·양인 후보를 별도로 판정한다.
2. 종재·종관살·종아·종왕·종강·가종 등을 검토한다.
3. 특수격 후보가 미해결 상태이면 관련 용신 판단을 보류한다.
4. 특수격 성립 기준은 별도 전문가 승인 규칙을 따른다.

제3조. 격국 성패와 상신

R-010: 성패·구응

1. 각 격국의 성립 조건을 평가한다.
2. 격국을 훼손하는 후보 관계를 탐지한다.
3. 구제 가능한 상호작용을 검토한다.
4. 미확정 합충·합화로 성격·파격을 확정하지 않는다.
5. 격국의 성립·훼손·구응·미확정 상태를 구분한다.

R-011: 격국용신·상신

1. 월령과 승인된 취격 규칙에 따른 격국의 중심 요소를 저장한다.
2. 격국의 성립을 돕는 상신을 선정한다.
3. 격국을 방해하는 요소를 별도로 기록한다.
4. 상신의 유효성은 통근·위치·상호작용과 연결해 검토한다.
5. 격국용신을 억부용신과 동일한 값으로 취급하지 않는다.

제4조. 용신 후보 분석

R-012: 억부용신

1. R-006의 승인된 강약 분석 결과를 입력받는다.
2. 생조·억제·설기·소모의 적합성을 검토한다.
3. 특수격 후보가 있으면 일반 억부법을 바로 적용하지 않는다.
4. 후보 오행이 격국 구조를 훼손하는지 확인한다.
5. 강약이 미확정인 경우 억부용신의 확정도 보류한다.

R-013: 조후·통관·병약

1. 조후는 일간과 월령의 한난조습 관계를 검토한다.
2. 통관은 상극 관계 사이의 유효한 생조 연결을 검토한다.
3. 병약은 문제 구조를 확정한 후 이를 완화하는 요소를 찾는다.
4. 세 체계의 결과는 각각 다른 필드에 저장한다.
5. 어느 체계도 오행의 단순 개수만으로 용신을 확정하지 않는다.

제5조. 종합과 충돌 처리

R-014: 종합 용신 판단

1. 이론별 용신 후보를 독립적으로 보존한다.
2. 동일 오행이 반복 추천된 이유를 기록한다.
3. 이론별 후보가 충돌하면 원인을 분석한다.
4. 확정되지 않은 근거를 AI가 임의로 보완하지 못하게 한다.
5. 필요한 근거가 없으면 최종 용신 판정을 유보한다.
6. 운영용 단일 용신이 필요한 경우 명시적인 목적과 승인 규칙을 요구한다.

제6조. 필수 상태값

격국과 용신 관련 판단은 다음 상태를 가진다.

* not_evaluated: 아직 분석하지 않음
* candidate: 후보 탐지
* review_required: 전문가 또는 추가 규칙 검토 필요
* approved: 승인된 규칙으로 판정 완료
* blocked: 선행 계산 또는 검증 문제로 판정 불가

후보를 승인된 결과처럼 표시할 수 없다.

제7조. 근거 추적

모든 판단은 다음 데이터를 포함한다.

* 원국 및 만세력 계산 ID
* 적용한 고전 문헌 및 해당 장
* 문헌 본문과 후대 주석의 구분
* 내부 규칙 ID 및 버전
* 적용된 지장간·분일표 버전
* 관련 천간·지지와 십성
* 판단 조건 및 충돌 조건
* 전문가 검증 상태
* 판단 결과와 보류 사유

제8조. AI 상담문 생성 정책

AI는 격국의 이름이나 용신을 독자적으로 계산하지 않는다.

승인된 명리학 분석 근거만을 사용하여 상담문을 생성한다.

이론적 해석과 이용자의 실제 성격·과거 사건·미래 사건을 구분한다.

직업, 연애, 재물, 건강과 관련된 내용을 검증 없이 단정하지 않는다.

제9조. 검증

최소한 다음 검증을 수행한다.

1. 10일간 × 12월지 기본 격국 조합 검증
2. 지장간 투출과 잡기 취격 검증
3. 건록·월겁·양인 및 특수격 검증
4. 격국 성립·훼손·구응 검증
5. 격국용신·상신의 역할 구분
6. 억부용신과 조후용신의 독립성 확인
7. 통관·병약 구조의 실제 조건 검사
8. 미확정 합충·합화와 사령 이견 처리
9. 동일 계산 입력의 결과 재현성 확인
10. AI의 임의 용신 변경 및 미승인 판단 출력 방지

제10조. 운영 승인

각 규칙은 문서 채택 후에도 실제 코드 구현과 자동 테스트, 전문가 사례 검증을 통과해야 운영용으로 승인할 수 있다.

선행 규칙의 미검증 사항이 관련 판단에 영향을 미치는 경우 해당 결과를 확정하지 않는다.

본 규칙서는 격국·용신의 이론적 일관성과 소프트웨어 품질을 높이기 위한 것이며, 미래 사건의 예측 정확성을 보증하지 않는다.
