## 사실과 다른 점(충돌) 기록
1. R-001 원문은 지원 연도를 **1900–2100**으로 적었지만 이 저장소 앱의 현재 지원 범위는 **1900–2050**이다(`support-range.ts`).
2. R-001 원문은 "음력 입력 변환 기능 없음"이라 적었으나, 이 저장소 앱은 별도 라이브러리로 음력·윤달 변환을 이미 갖고 있다(교차 검증 46,386건 일치). 원문은 R-001 코어 한정 진술이다.
3. 마스터의 "야자시·진태양시" 정책: 원문은 정책 서명 전 미구현. 이 저장소는 기본 자정 교체(`ziHour:'MIDNIGHT'`)와 법정시 기준을 쓴다.
4. 마스터 머리말은 GPT=상담문 생성, Gemini=독립 감수로 두고 **둘 다 원국·격국·용신 최종 판정 권한이 없다**고 한다. 이 저장소의 현재 AI 파이프라인(GPT 작성, 코드 검수)과 방향이 맞고 Gemini 감수는 아직 없다.

## R-003 지장간표 대조 (사실, 코드는 바꾸지 않음)
붙여넣은 R-003 원문은 《연해자평》 지지장둔가를 고정표로 채택한다. 이 저장소 `engine/manse/src/hidden.ts`의 `STANDARD` 표와 비교하면:
- **본기(정기) 12개는 모두 일치.**
- **구성원은 7개 지지(丑 寅 辰 巳 未 申 戌)에서 일치, 5개 지지에서 다르다**: 엔진에는 子에 壬, 卯에 甲, 酉에 庚, 午에 丙, 亥에 戊가 더 들어 있다(원문은 子 癸 / 卯 乙 / 酉 辛 / 午 丁·己 / 亥 壬·甲).
- 의미: 이 저장소의 `STANDARD` 는 "널리 쓰이는 월률분야 표"(코드 주석에 외부 검증 못 함)이고, R-003 원문과 **다른 표**다. R-004(통근)는 R-003의 표를 입력으로 요구하므로, 통근을 구현할 때 엔진 표를 그대로 쓰면 이 5개 지지에서 통근 결과가 원문과 달라진다. 어느 표를 기준으로 할지는 사용자(전문가)가 정해야 하며, 확정 전에는 원문 표를 기준으로 삼고 엔진 표는 건드리지 않는다.
- 사령 분일표(`SMTH_30_V1`, `MODERN_30_CANDIDATE_V1`)의 수치 원문은 R-003 원문에도 들어 있지 않다(규칙집 이름과 방식만 있음). 엔진의 사령 계산(`commandingStem`)이 어느 쪽인지도 미확인.
