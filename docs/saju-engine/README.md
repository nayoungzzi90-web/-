# 명리 엔진 기준서 보관함 (docs/saju-engine)

사용자가 제공한 R-001~R-015 기준서 원문과 검증 자료를 **원문 그대로** 보관하는 곳이다. 규칙 상태는 `RULE_REGISTRY.md`에 따로 적는다.

## 지켜야 할 원칙
1. `source/` 안의 원문은 **고치지 않는다.** (복원 마스터 안의 원문 보존 구간과 개별 파일은 같은 내용이며, R-010~R-012는 사용자가 따로 올린 파일과 바이트 단위로 동일함을 확인했다.)
2. 정책 채택 ≠ 코드 구현 ≠ 테스트 통과 ≠ 전문가 검증 ≠ 출시 승인. 각각 따로 기록한다. **어떤 항목도 근거 없이 APPROVED/VERIFIED로 바꾸지 않는다.**
3. R-001~R-015 원문은 모두 확보됐다(R-002~R-009는 2026-10-29에 사용자가 붙여넣은 것, 모두 DRAFT-1/검토 대기). 단 이것이 **채택·구현·전문가 검증**을 뜻하지 않는다. 원문에 없는 세부(예: 사령 분일 수치)는 지어내지 않고 `UNVERIFIED`로 둔다. 복원 정책 요약은 방향일 뿐 세부 알고리즘이 아니다. 세부를 지어내지 않는다.
4. 기준서에 있는 R-001~R-015 번호는 **명리 규칙 번호**다. Lovable 쪽에서 쓰던 `R001`(음력·절입 정밀 감사)·`R015`(로그인·DB 권한 감사)와 이름이 겹치니 구분해서 쓴다. 이 저장소의 `lovable-app/docs/R001_*`, `R015_*` 는 후자다.

## 라이선스 주의 (`R001_precision_validation`)
이 폴더의 절기 시각표는 Swiss Ephemeris(AGPL/상용 이중 라이선스)로 계산한 값이고 `audit_independent.py`는 `pyswisseph`를 부르는 개발용 스크립트다. **서비스 런타임에 포함하지 않는다.** 저장소를 공개로 두는 동안 재배포 문제가 없는지 법률 검토 전까지 외부 배포를 하지 않는다(저장소 비공개 전환 권장). 이 저장소의 자체 엔진(`engine/manse`)은 JPL DE421 자체 환산을 쓰고 Swiss 자료는 코드·데이터로 넣지 않는 정책이었다.
