## 3. 원문에 있는 사실 중 이 저장소에 없는 것
- 격리 Staging(R015 QA 샌드박스 `f18ad423-…`) 결과: 실제 JWT A/B RLS 34/34, 익명 접근 5/5, 호스팅 요청 제한 시험 — Lovable 쪽 증거이며 이 저장소에는 파일이 없다.
- 운영 Supabase 현황(공개 6개 표 RLS 활성, GRANT 과다, 요청 제한 RPC 없음)은 우리 `lovable-app/docs/R015_PRODUCTION_READINESS_2026-10-18.md`와 같은 방향이다(운영 읽기 전용 스냅샷 기반).
