# J. 실제 AI 연결 — 추천 설정 (가격은 공식 페이지에서 반드시 재확인)

## 추천
- **모델:** `gpt-5.4-mini` (품질·가격 균형). 시험·초안 비교용으로 `gpt-5.4-nano`. 처음부터 플래그십(GPT-5.5급)은 쓰지 않는다.
- 가격(제3자 집계, 공식 아님): 5.4-mini 입력 $0.75 / 출력 $4.50 (100만 토큰당), 5.4-nano $0.20 / $1.25. → 설정 전에 openai.com 공식 가격으로 교체.
- **원가 추정(기본 사주 1건):** 입력 약 1.5만 토큰 + 출력 약 6천 토큰 + 검수 재시도 50% 가정 → 약 $0.05~0.06 ≈ 70~90원. 900원 매출 대비 원가 10% 안팎, 결제 수수료(예: 3%)를 더해도 마진 충분. 심층 연애운(1,800원)·심층 사주(2,700원)는 출력이 더 길어도 여유.
- **하루 예산:** 시작은 **약 1만 원/일**(= $7 안팎, 약 100~120건 분량). 첫 2주 실제 사용량을 보고 조정.
- **1건 상한:** 기본 $0.15(약 200원), 연애운·심층은 $0.30. 초과 예상이면 호출 전에 중단(코드에 구현됨).

## 설정(서버 비밀값, 채팅·저장소에 키를 붙여넣지 말 것)
```
supabase secrets set LLM_PROVIDER=openai OPENAI_API_KEY=<새로 만든 키> LLM_MODEL=gpt-5.4-mini \
  LLM_PRICE_IN_PER_M=<공식 입력가> LLM_PRICE_OUT_PER_M=<공식 출력가> \
  LLM_REPORT_BUDGET_USD=0.15 LLM_REPORT_BUDGET_USD_LOVE_DEEP=0.30 LLM_DAILY_BUDGET_USD=7
```
- OpenAI 대시보드에서도 **월 사용 한도(hard limit)** 를 따로 걸어 이중 안전장치로 쓴다.
- 문제 시 `LLM_KILL_SWITCH=true` 로 즉시 중단.

## 연결 후 할 일(키가 준비되면)
1. 샘플 10~20명으로 실제 1건당 토큰·원가 측정 → 이 문서의 추정 갱신, 마진 재계산.
2. 품질 검수(단정 표현·분량·사실 일치) 통과율 확인. 규칙형(템플릿) 풀이와 나란히 비교해 유료 가치가 있는지 판단.
3. 규칙형 풀이를 폴백으로 유지(AI 실패·예산 초과 시).
