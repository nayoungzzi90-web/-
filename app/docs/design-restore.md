# 시안 복원 기록 — 조선 민화풍 "오행 친구들" (2026-11-11)

원본: 사용자가 준 시안 이미지 1장(1024×1536, 화면 4개). 이미지 생성으로 만든 것으로 보이며, 작은 글씨가 깨져 있고 캐릭터는 한 명이 100픽셀 안팎이다.
구현 위치: `app/src/routes/restore.*.tsx`(비교용 주소 `/restore/guide|home|result|charge`, noindex), 컴포넌트 `app/src/components/minhwa/`, 토큰 `app/src/styles.css`의 `.skin-minhwa`.
운영 화면(`/`, `/input` 등)은 바꾸지 않았다. 마음에 들면 `.skin-minhwa` 로 운영 화면 껍데기를 교체한다.

## 1. 원본에서 확실히 보이는 것 (복원 확신 높음)
- 팔레트: 한지 #F7F0E3, 먹 #2B2320, 단청 홍 #B83A26, 청록 #2F7068, 쪽빛 #2D3E73, 황토 노랑 #E2B04A, 엽전 황동 #C99A4B.
- 레이아웃: 홈(입력), 결과(일주 카드 + 원국표 + CTA), 충전(남색 보유 카드 + 상품 3종 + 결제 버튼), 가이드(캐릭터 5카드 + 팔레트 + 글꼴), 하단 탭 4개(홈/오늘/보관함/엽전).
- 컴포넌트: 굵은 먹 외곽선 버튼 + 오른쪽 화살표, 양력/음력·여/남 토글(선택된 쪽만 색 채움), 둥근 입력창 + 오른쪽 아이콘, 카드(가는 황토 테두리, 둥근 모서리), 추천 배지(카드 위에 걸치는 붉은 탭), 엽전 배지.
- 캐릭터 5종: 솔이(검은 갓 + 초록 한복), 댕이(붉은 한복 + 댕기), 호동이(아기 호랑이 + 부채 + 파란 옷), 달토(흰 토끼 + 두루마리), 거북기(민트 거북 + 파란 옷).

## 2. 추정 복원(원본을 따라 새로 그린 것)
- 한옥 마당 배경(해, 먼 산, 소나무, 지붕, 기둥, 등불, 족자, 돌담, 구름, 새): 원본에 글자가 박혀 있어 그대로 못 쓰고 도형으로 다시 그렸다. 구성과 색만 같다.
- 엽전 아이콘, 하단 탭 아이콘, 화살표: 직접 그림.
- 족자 문구: 원본은 글자가 깨져 있어 "오늘도 좋은 운이 가득해요"로 대체.

## 3. 불확실·주의
- **캐릭터는 원본에서 잘라낸 저해상도 임시 에셋**(높이 약 360px, 4배 확대). 크게 쓰면 흐려진다. 가장자리(특히 달토)는 일부 거칠다. 최종 서비스에는 같은 그림의 고해상 원본(투명 PNG 캐릭터 시트)이 필요하다.
- 원본 이미지의 권리는 사용자가 만든 시안이라는 전제다. 이미지 생성물의 저작권 보호는 약할 수 있어 상표·굿즈 전개 전에 사람 작가의 마무리를 권한다.
- 원본의 깨진 글씨("엄거리 소녀", "달토끼" 등)는 그대로 옮기지 않고 정리했다. 속성 줄은 "목 木 · 푸른 선비" 형식으로 통일했다.
- **원본과 일부러 다르게 한 것**
  - 충전 가격: 시안(990원, 3,900원, 6,900원, "21%·30% 절약")이 아니라 현행 정책(1닢=900원, 충전 팩 1~4닢)을 썼다. 결제는 꺼져 있어 버튼은 비활성.
  - 오타 "업전" → "엽전".
  - 원국표 아래 십성 라벨(비견·정인 등)은 검증 전 규칙이라 쓰지 않고 오행 이름만 적는다.
  - 결과의 일주 이름·문구는 실제 계산 엔진 결과(샘플: 庚辰). 일주 캐릭터는 일간 오행에 맞춰 바뀐다(시안은 솔이 고정).
  - "엽전 1개로 전체 풀이 열기"는 아직 상품이 없어 "전체 풀이 준비 중".

## 4. 스타일 토큰 (`.skin-minhwa`)
색은 위 팔레트. 카드 반경 20px, 버튼 반경 24px, 외곽선 굵기 2.5px(먹), 카드 테두리 1.5px #D8C3A0. 제목 글꼴 주아, 본문 고운돋움. 글자 크기: 제목 34/22/20px, 본문 15~17px, 보조 11~13px.

## 5. 컴포넌트 (`components/minhwa/ui.tsx`)
CoinIcon, CoinBadge, MhHeader(뒤로/제목/엽전), MhButton(주홍 그라데이션 + 먹 외곽선 + 화살표), MhToggle, MhField, RecoBadge, MhTabBar, FriendCard, FriendImg. 배경은 `Scene.tsx`(Scene, Cloud, Scroll). 캐릭터 정의는 `data.ts`.

## 6. 에셋 구조
```
app/public/restore/characters/{solri,daengi,hodongi,dalto,geobuki}.png  (임시, 저해상도)
app/src/components/minhwa/{data.ts,ui.tsx,Scene.tsx}
```

고해상 원본이 오면 같은 파일명으로 교체하면 된다(투명 PNG, 높이 800px 이상 권장).

## 8. 패키지 통합 기록 (2026-11-11, `ohaeng_friends_claude_code_COMPLETE.zip`)
- 패키지는 React/Vite 데모(홈·결과·충전·가이드)와 장식 SVG 세트다. 화면은 이미 `/restore/*`와 운영 화면에 구현되어 있어 **화면 코드는 가져오지 않았다**.
- **캐릭터 PNG는 쓰지 않았다**: 패키지의 5종은 360px 저해상 컷아웃이고, 현재 저장소에는 사용자가 새로 그린 900px 버전이 있다.
- **가격은 쓰지 않았다**: 패키지의 990/3,900/6,900원 예시는 현행 정책(1닢=900원, 충전 팩 1~4닢)과 달라서 제외.
- **가져온 장식**(`public/restore/deco/`): coin.svg(엽전 아이콘), cloud.svg, blossom-corner.svg(입력·고민 화면 우상단), night-sky.svg(로딩 화면 배경). SVG에 스크립트·외부 링크가 없음을 확인했다.
- 패키지의 SVG는 시안에서 분리한 원본이 아니라 새로 만든 근사 에셋이다(패키지 README 명시).
